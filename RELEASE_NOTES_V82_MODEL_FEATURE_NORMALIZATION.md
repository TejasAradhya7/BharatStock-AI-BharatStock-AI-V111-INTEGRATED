# V82 — Prediction feature normalization

## Scope
This release changes only the existing daily direction model's input feature engineering. No dashboard features were added.

## Changes
- Converts MACD and MACD signal into ratios relative to closing price.
- Converts SMA20, SMA50, and EMA20 into relative price gaps instead of absolute price levels.
- Converts ATR into a price-normalized volatility ratio.
- Adds five-session close-to-close momentum as a causal feature.
- Keeps the chronological train/test split, expanding-window walk-forward evaluation, majority-class baseline, and research-only warning.
- Explicitly states that an 80–90% directional hit rate is not demonstrated or guaranteed.

## Verification
- Full backend tests: **101 passed**, 4 deprecation warnings.
- Holdout CSV evidence audit: **passed** for all four supplied prediction files.
- Python syntax is exercised by the backend test run.

## Accuracy evidence and limitation
The existing supplied holdout predictions—not predictions generated by the changed feature pipeline—recompute to 53.33% (1-bar), 54.49% (3-bar), 49.74% (5-bar), and 52.30% (10-bar) accuracy at a 0.50 threshold. The 3-bar ROC-AUC is 0.5497. This is weak predictive evidence and does not support an 80–90% accuracy claim.

A fresh market-data retraining comparison could not be run in this environment because `yfinance` is not installed and no raw historical OHLCV training dataset is included in the clean project folder. Therefore this change is a code-level improvement, not a verified improvement in out-of-sample accuracy. Run the model against fresh historical data and compare identical chronological folds before claiming accuracy gains.
