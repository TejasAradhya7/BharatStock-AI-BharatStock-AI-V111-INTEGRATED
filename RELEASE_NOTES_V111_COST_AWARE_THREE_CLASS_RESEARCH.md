# BharatStock AI V111 — Cost-Aware Three-Class Research

## Purpose

V111 adds a separate three-class intraday research track to the existing binary walk-forward benchmark. The existing binary target, models, endpoint, dashboards, trading gate, and historical results are retained.

## What changed

- Added `Target_3class` to the engineered candle frame as a convenience label using a 20 bps default round-trip neutral band. Rows without a complete future entry/exit pair remain unlabeled.
- Added `walk_forward_three_class_intraday`, which recomputes labels from the experiment's configured `cost_bps` (round trip = 2 × `cost_bps`).
- Class definitions use executable return from next close to close four bars after the signal:
  - `DOWN` (0): return below negative round-trip cost.
  - `NO_TRADE` (1): return inside the cost band, including its boundaries.
  - `UP` (2): return above positive round-trip cost.
- Evaluates Random Forest, HistGradientBoosting, and Logistic Regression with expanding chronological folds, a four-row boundary purge, and no shuffling.
- Reports per-fold class counts, confusion matrices, accuracy, balanced accuracy, macro precision/recall/F1, multiclass Brier score, log loss, and a majority-class baseline.
- Adds the result under `evaluation.three_class_evaluation` on the existing intraday research endpoint response.
- Adds explicit reasons when validation cannot approve a long/flat trading threshold.

## Safety and interpretation

- The three-class evaluation is a research diagnostic, not an order signal.
- `trading_enabled` is always false for this evaluation.
- It does not force trades, force class balance, optimize on test labels, or promise a target accuracy.
- The neutral band is a simplified configured cost proxy. It is not a complete Indian broker cost model and does not include all taxes, spread, slippage, market impact, or latency.
- The existing binary evaluation remains available for backward compatibility.

## Validation

- Full backend suite: execution exceeded the available test-run time limit in this environment; no full-suite pass is claimed.
- Real-market V111 results must be generated by rerunning the API against current Upstox historical candles after applying the update.
